# Mẫu bài nộp TabQA

Đây là bộ khung Python tối thiểu cho giao diện bài nộp. Docker chạy trực tiếp `main.py`; hãy thay phần tạo đáp án trống bằng chương trình của đội và thêm các bước cài thư viện cần thiết vào `Dockerfile`.

Khi chạy trực tiếp mà không truyền `--output`, kết quả được ghi vào `output/team001/submission.csv`.
